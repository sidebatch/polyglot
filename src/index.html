동사 て형

て형은 "〜하고", "〜해서"처럼 문장을 이어주거나 요청·진행형을 만들 때 쓰는 기본형

1류 동사어미에 따라 변하는 5단 동사

어미변화예시
く→ いて 書かく → 書かいて쓴다 → 쓰고
ぐ→ いで 泳およぐ → 泳およいで수영한다 → 수영하고
ぬ · ぶ · む→ んで 死しぬ → 死しんで죽다 → 죽고
遊あそぶ → 遊あそんで논다 → 놀고
飲のむ → 飲のんで마신다 → 마시고
う · つ · る→ って 歌うたう → 歌うたって노래하다 → 노래하고
立たつ → 立たって일어서다 → 일어서고
走はしる → 走はしって달리다 → 달리고
す→ して 押おす → 押おして밀다 → 밀고
⚠️ 예외: 行いく(가다)는 く로 끝나지만 行って가 된다. 이거 하나만 외우면 된다.

2류 동사る 빼고 + て

食たべる → 食たべて 먹다 → 먹고
寝ねる → 寝ねて 자다 → 자고

3류 동사불규칙 2개, 통째로 외우기

する → して · 来くる → 来きて

형용사

い형용사 / な형용사 — 연결(묘사)할 때와 부정형이 다르다

い형용사 — 어미가 い로 끝남 (明るい 밝다 · 大きい 크다)

나열(묘사)할 때: い → くて
ex) 작고 귀여운 가방 → 小ちいさくてかわいいカバン
부정형: い 빼고 + くない
ex) 大おおきくない (크지 않다)

な형용사 — 명사 앞에서 + な

형용사뜻
すてき 素敵すてき멋짐
にぎやか 賑にぎやか활기참
ささやか 細ささやか아담함 · 작음
きれい 綺麗きれい예쁨 · 깨끗함
명사 꾸밀 때: 형용사 + な
ex) 멋진 가게 → すてきなお店みせ · 깨끗한 가게 → きれいなお店みせ
부정형: じゃない / ではない
ex) すてきじゃない · ささやかではない
💡 회화에서는 じゃない을 훨씬 많이 쓴다.

〜たい / 〜たくない

"〜하고 싶다 / 〜하기 싫다" — 동사 ます형에 붙인다

肯定: ます형 + たい
行いく → 行いきたい (가고 싶다) · 食たべる → 食たべたい (먹고 싶다)
否定: ます형 + たくない
行いきたくない (가기 싫다) · 食たべたくない (먹기 싫다)
