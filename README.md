# Polyglot

대화·사진·노트에서 모은 언어별 레퍼런스. (from 밍Lab)

🌐 https://sidebatch.github.io/polyglot/

## 콘텐츠 현황

언어 8개 탭 (일본어 · 영어 · 프랑스어 · 러시아어 · 스페인어 · 독일어 · 중국어 · 아랍어).
자료가 있는 언어부터 탭·광장 앞에 정렬되고, 언어 안에서는 최신 자료가 맨 위에 온다.

- 🇯🇵 일본어 (자료 제공 · 카린)
  - 기초 문법 노트: 동사 て형(1·2·3류), 형용사(い/な), 〜たい/〜たくない
  - 동사 활용형 6종: 의지형 · 가능형 · 가정형 · 수신형 · 사역형 · 사역수신형
  - 자동사 · 타동사 쌍 39쌍
- 🇬🇧 영어 (자료 제공 · 고잉)
  - 예문으로 익히는 where (관계절을 예문 흐름으로 익히는 귀납식 카드)
- 🇷🇺 러시아어 (자료 제공 · 밍밍)
  - 1식 ПОНИМАТЬ / 2식 ГОВОРИТЬ 현재형 활용표
- 🇫🇷 🇪🇸 🇩🇪 🇨🇳 🇸🇦 프랑스어 · 스페인어 · 독일어 · 중국어 · 아랍어: 준비 중

맨 아래에는 모든 언어 공통 **마인드셋** 코너 (칼럼: "단어는 나무 한 그루" · 고잉).

## 기능

- 보기 모드 2가지 (⚙️ 설정): 탭 / 그리드(언어 카드 광장) — localStorage 저장
- 인터페이스 언어 9개 (🌐): ko/ja/en/fr/ru/es/de/zh/ar — UI 문자열만 번역, 자료 내용은 원본 그대로
- 국기는 이모지가 아닌 내장 PNG 이미지 (PC에서도 표시, 오프라인 동작)
- 자료는 아코디언: 카드 탭 → 상세 펼침, 제공 표기는 상세 하단 "📎 자료 제공 · 이름 · 날짜"
- 카드별 딥링크/공유: 펼친 상세 아래의 공유 버튼으로 링크 복사·공유, 링크를 열면 해당 언어 화면에서 그 카드가 펼쳐진 채로 열림 (마인드셋 칼럼 포함)
- 펼침 표시는 원형 칩(얇은 꺽쇠) — 열면 회전
- NEW 배지: 지난 방문 이후 새로 올라온 자료 카드에 표시 (기기별 방문 기록 기준)

## 구조

```
src/           소스 (직접 수정하는 곳)
  index.html   마크업 (자료 패널·엔트리)
  styles.css   스타일
  i18n.js      콘텐츠 언어 8개 + UI 번역 9개 + 언어별 액센트/국기
  app.js       탭/광장/아코디언/UI언어/딥링크/NEW 배지/업데이트 확인 로직
  sw.js        서비스워커 (네트워크 우선 + 오프라인 폴백)
  manifest.webmanifest
  icons/       앱 아이콘 + 국기 PNG
docs/          빌드 결과물 (배포본, Pages가 여기서 서빙)
build.mjs      빌드 스크립트 (esbuild 압축, 버전 스탬프, docs/ 생성)
tests/         기능 테스트 (jsdom, run-tests.js — 딥링크·공유·칩·NEW 배지 등 16개)
```

## 빌드 & 배포

```sh
node build.mjs          # docs/ 재생성 (버전 = git 커밋 수, 푸터와 설정에 vN으로 표시)
node tests/run-tests.js # 빌드 결과물 대상 기능 테스트
```

수정 → 빌드 → 테스트 → 커밋 → 푸시 순서로 작업. Pages는 `main` 브랜치의 `docs/` 폴더를 서빙한다.
배포본은 압축되어 있어 소스 보기로는 원본 코드를 바로 가져가기 어렵다.

## 자료 추가 규칙

자료는 밍Lab 대화·사진·노트로 받아 카드로 정리해 올린다.

- 내용은 원본 그대로 보여준다. 요약하거나 다시 쓰지 않고 카드로 나눠 담는다.
- 제공자의 표기 의도는 그대로 보존한다 (예: 러시아어 자료의 대문자 어미 강조).
- 제공 표기는 펼친 상세 하단에 "📎 자료 제공 · 이름 · 날짜" 형식으로 붙인다.
- 새 자료는 목록 끝에 추가한다. 화면에서는 최신순으로 정렬돼 자동으로 맨 위에 온다.
- 직접 만드는 콘텐츠는 예문을 먼저 보여주고 패턴을 느끼게 한 뒤, 문법 용어는 맨 끝에 이름표로 붙이는 귀납식으로 쓴다.

## PWA

`manifest.webmanifest` + `sw.js` + 아이콘 포함. 폰 브라우저에서
'홈 화면에 추가'로 설치하면 단독 앱처럼 실행되고 오프라인에서도 열린다.

서비스워커는 **네트워크 우선** 전략: 온라인이면 새로고침만으로 항상 최신 버전이 보이고,
오프라인일 때만 캐시로 폴백한다. ⚙️ 설정에 수동 "업데이트 확인" 버튼도 있다.
앱 아이콘은 골드 세리프 P (AI 생성 후보 중 선택), 국기는 flagcdn PNG를 내려받아 내장.
